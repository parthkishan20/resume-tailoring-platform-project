## D-66 harness guard

D-66 (PLAN.md, defect register): `litellm/__init__.py` calls `dotenv.load_dotenv(override=False)`
at import time, which fills any environment variable *absent* from `os.environ` by walking up
from the working directory to find a `.env` — in this repo's layout, the real `OPENAI_API_KEY` at
the repo root. One test used to delete that key as its precondition and briefly leaked the real
value into the process as a result. That test was already fixed (present sentinel instead of
deletion); this task builds the guard PLAN.md's D-66 entry said was still missing.

**Why a fixture alone cannot close this.** pytest fully collects — imports — every test module
before running any test's setup phase, and three modules in this suite
(`test_llm.py`, `test_llm_bounds.py`, `test_backend_wiring.py`) import
`resumetailor.llm.litellm_adapter`, hence `litellm`, at module level. That import, and
`litellm`'s own `load_dotenv` call, happens at *collection* time — before any fixture, including
one with `scope="session", autouse=True`, has run its setup code. The only hook pytest offers
that runs earlier than collection is the import of `conftest.py` itself.

**The guard:** `backend/tests/conftest.py` now monkeypatches `dotenv.load_dotenv` to a no-op at
module import time (not inside a fixture body). Because `litellm/__init__.py` does
`import dotenv as _dotenv; _dotenv.load_dotenv(...)` — an attribute lookup at call time, not a
name bound once at its own import — mutating the attribute on the shared `dotenv` module object
before `litellm` is ever imported anywhere in the process is sufficient, regardless of how or
when `litellm` (or anything else) imports it afterward. The original function is kept as
`REAL_LOAD_DOTENV` in `conftest.py` for the regression test below.

**Regression test:** `backend/tests/test_harness_guards.py`, three tests:
1. `dotenv.load_dotenv` is confirmed to be the guard, not the real function (a marker attribute).
2. The exact D-66 mechanism is reproduced against a planted fixture, not the real repo `.env`:
   a temp `.env` defines a real-looking credential, the corresponding env var is deleted, then
   `dotenv.load_dotenv(override=False)` — litellm's exact call — is invoked directly; asserts the
   value is not filled.
3. Proves test 2 is load-bearing rather than vacuous: calls `REAL_LOAD_DOTENV` (the saved,
   pre-patch function) against the same planted fixture and confirms it *does* leak the value —
   the counterfactual the guard exists to prevent.

Verified stable: `make check`'s pytest target, plus `pytest -p randomly --randomly-seed={1,2,3}`,
all 339 tests pass under each seed.
